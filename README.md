# تحديث شيت Ejadah

تطبيق Streamlit: ارفع الملف الأساسي + ملف التحديث، اختار التاريخ، نزّل الملف المحدّث.

الملفات: `app.py` (الواجهة) · `processing.py` (المنطق) · `requirements.txt`

التشغيل محلياً: `pip install -r requirements.txt && streamlit run app.py`
على Streamlit Cloud: اختار الريبو و Main file = `app.py`.
